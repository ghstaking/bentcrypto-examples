# x402 Notes for BentCrypto

BentCrypto uses x402 v2 fixed-price (`exact`) payments on Solana mainnet.

## Payment flow

1. Client sends a normal HTTP GET request.
2. BentCrypto responds with HTTP 402 and a `payment-required` header.
3. The buyer's x402 client validates the requirement and signs locally.
4. The buyer retries with the payment proof.
5. BentCrypto verifies/settles payment and returns the resource response.
6. Settlement metadata is returned in the `payment-response` header.

## Why the example clients preflight

The JavaScript and Python examples first perform an unpaid request and inspect the challenge. They refuse to sign unless the network, asset, amount, and receiver all match the expected BentCrypto production configuration.

This is an additional safety layer for examples that use real Solana mainnet USDC.
